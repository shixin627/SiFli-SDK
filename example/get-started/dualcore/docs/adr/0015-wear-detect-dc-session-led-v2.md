# 0015 — 配戴偵測 v2:DC 會話主導(脈搏只守冷啟動)

日期:2026-06-12
狀態:Accepted
前置:ADR 0012(滑動窗)、0013(接觸中斷重確認)、0014(診斷上報)
取代:0013 的接觸中斷重確認機制(整套移除)
相關檔案:`src/modules/algorithm/WearDetect/wear_detect.c`

## 問題(整夜實測定罪)

0014 的診斷通道取得睡眠機整夜數據(2026-06-11 20:24 → 06-12 09:45,
13.3 小時),證明 0012+0013 修法在深睡仍系統性失效:

- **82% 時間誤判未配戴**;03:15→08:51 連續卡 OFF 5.5 小時
- 期間 DC 穩定在 43k+(配戴帶內)— 接觸訊號明明在,**卡死的是
  「恢復要脈搏」**:48 次 probe 開、40 次過期,深睡 PI 過不了 0.0010
- 翻身(動作+DC 瞬跌)觸發 0013 重確認 → 深睡確認不了 → 掉線(7 次)
- 實測這隻錶:戴著 DC 39.0k~44k(中位 43.4k)、脫下表面 30.5k~35.5k、
  睡眠 dip 最低 36.4k — **接觸與否在 DC 上可分,固定 42000 門檻卻
  切穿配戴帶**

結論:任何把脈搏放進「維持/恢復」路徑的設計,夜裡必死。主流方案
(Apple/Goodix/Maxim)的共同形狀:**脈搏(或等價的膚質判別)只守
第一次確認;之後全靠接觸證據 + per-unit 校準 + 情境慣性**。

## 決策(v2 規則)

1. **冷啟動(會話第一次戴上)**:沿用 windowed 脈搏閘(PI≥0.0010 +
   變動度,3-of-8)+ DC ≥ `DC_ABS_FLOOR`(36000)。
2. **脈搏確認永遠重播種**(review blocker 修正):每一次脈搏確認的
   ON 都 `worn_dc_base = 當下 DC` — 脈搏是最高信任證據;這同時修掉
   「偽影種子中毒永不翻身」(實測偽影可播在 56.9k 把真腕 43.4k 鎖在
   帶外)並自動保證入口⊆持有的單調性(off_thr=0.8×剛確認的 DC)。
3. **ON 維持**:DC > max(0.80×base, 36000) 即保持;PI 完全不參與。
   EMA 微調 base 僅在「本段 ON 由脈搏錨定」時進行(暖恢復段不學習,
   防 band 重合表面把 base 拖走 — review 實測桌面把 base 43.5k 拖到
   39.1k),且非對稱:向下 1/64/eval、向上 1/256(防壓迫感測器的高
   DC 期把 off_thr 抬過睡眠 dip 的 36.4k 邊際)。充電時凍結。
4. **暖恢復(關鍵新機制)**:OFF 且 base 有效且未充電,DC 回到
   band([0.88,1.15]×base)**且 ≥ 36000**(入口⊆持有,否則確定性
   振盪)即投 ON(3-of-8),**不要求脈搏** — 錯誤的 OFF 在秒級自癒,
   「卡死數小時」失效類被結構性消滅。
5. **ON→OFF 雙速遲滯**:DC 低於門檻連續 8 evals(12 秒,streak 內
   有動作=摘錶特徵)或 20 evals(30 秒,全靜止=保護睡眠 dip)。
6. **充電(is_plugged)**:封鎖暖恢復 + 凍結 EMA;**OFF 狀態下充電
   即清除 base(會話邊界)** — 被表面學壞的 base 壽命至多一個充電
   週期;**不**強制 OFF(本產品允許邊充邊戴,v28 語意)。
7. bypass 開關切換時清投票窗/計數器(凍結期的陳舊證據不跨期)。

### 移除(0013 機制與死碼)

- 固定 `PPG_DC_LOW_THD 42000`(被 per-session 基線取代)
- 整套接觸中斷重確認(`contact_break_pending`/`reconfirm_evals_left`/
  `RECONFIRM_LIVE_EVALS`)— 夜間數據證明其「要脈搏」前提不成立
- `PI_THD_KEEP_ON`(定義後從未使用)、`IMU_RETRIGGER_COUNT` +
  `ctx.imu_retrigger_cnt`(死碼)、`HYSTERESIS_OFF`(被雙速取代)
- 診斷事件 6/7/8(BREAK_*)停止發射;wire 碼凍結保留、不重用

## 已知接受的取捨

1. **band 重合表面的暖誤回**:DC 落在配戴帶內的表面(實測早上桌面
   偶讀 39~40k)會暖恢復成假配戴、可能振盪。單綠光通道無法在無脈搏
   下分辨此類表面(主流靠 IR 比值/電容硬體)。代價有界:bg_hr 對
   表面燒幾個 burst(NO_LOCK,不產生假心率點)、上充電座即終止;
   產品優先序 = 睡眠連續 > 表面拒絕;設定頁「佩戴偵測」開關是逃生門。
2. **LCPU 重開機丟 base** → 退回冷啟動,夜裡重開機後需翻身+脈搏才
   回 ON(等同 v1 行為)。無聲重開機問題另案(reset reason 診斷)。
3. **base 永不過期**(充電不清、僅 reboot 清):換手/換腕戴造成的
   band 偏移由 EMA(~96 秒收斂 63%)與冷閘重新 seed 吸收。
