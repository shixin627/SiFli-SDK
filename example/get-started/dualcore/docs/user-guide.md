## 快速入門

第一次使用 Skaiwalk Watch,請依序進行:

1. **充電** — 把手錶背面磁吸對準充電底座,確認指示燈或畫面亮起。建議第一次充滿後再使用,以校正電量讀數。
2. **開機** — 按住側邊按鈕約 3 秒;畫面顯示啟動畫面後鬆開。
3. **配對手機** — 在手機端開啟 Skaiwalk App → 「新增手錶」,把手機鏡頭對準手錶上的 QR 碼(在 [QR Code App](#qr-code-qr-碼) 或互動引導畫面)即可完成 BLE 配對。
4. **跟隨引導** — 配對成功後,手錶會自動進入互動引導,帶你認識四個方向的抽屜與基本手勢。詳見 [第一次開機:互動引導](#第一次開機互動引導)。

完成後即可從錶盤開始日常使用。

## 認識手錶

| 規格 | 說明 |
| --- | --- |
| 螢幕 | 466 × 466 圓形 AMOLED 觸控螢幕 |
| 連線 | Bluetooth 5(BLE + 經典藍牙 HFP)|
| 感測器 | 6 軸 IMU、心率(PPG)、配戴偵測 |
| 操作 | 觸控、四方向滑動、側邊按鈕 |
| 充電 | 磁吸式充電底座 |

手錶採用 **雙核心架構**(HCPU 處理畫面與 AI 推論,LCPU 常駐感測器與週邊),目的是在不犧牲互動流暢度的前提下,維持長時間配戴。日常使用者不需要關心這個分工;進階使用者參考 [附錄](#附錄手勢與指令對照表)。

## 操作基礎

### 觸控與手勢

Skaiwalk Watch 全螢幕都是觸控區域,主要動作如下:

| 動作 | 說明 |
| --- | --- |
| **點擊(Tap)** | 確認、開啟、選取 |
| **長按** | 進入多選或顯示選項(部分 App)|
| **雙擊** | 縮放(相片)、快速切換 |
| **滑動(Swipe)** | 在抽屜與頁面之間切換,亦稱 Release 手勢 |

### Release 手勢與 Tap 手勢

手錶把所有手勢分成兩大類:

- **Release 手勢(滑動釋放)**:手指按下 → 朝某方向滑動 → 放開。
  用來在頁面之間切換、開啟抽屜、捲動列表。第一次開機的引導畫面會顯示一個動態示範圖,
  帶你練習 release 動作。
- **Tap 手勢(點擊)**:在某個項目上輕輕點一下,觸發該項目對應的功能。
  在 [指令列表](#指令列表左側抽屜) 中,Tap 用來執行畫面中央被選中的功能。

> **小技巧**:Tap 與 Release 的差別在於「有沒有方向」。沒有方向就是 Tap,有方向就是 Release。

### 四方向抽屜系統

從錶盤(中央頁面)往任一方向 release,會拉出對應的抽屜頁面:

```
                   (上方)
                  訊息中心
                     ▲
                     │
          (左側) ◀ 錶盤 ▶ (右側)
        指令列表           AI 頁面
                     │
                     ▼
                   控制中心
                   (下方)
```

具體手勢方向:

| 你的滑動方向 | 開啟的抽屜 | 內容 |
| --- | --- | --- |
| 手指向**右**滑動 | 左側抽屜 | 指令列表(主 App 啟動器) |
| 手指向**左**滑動 | 右側抽屜 | AI 頁面 |
| 手指向**下**滑動 | 上方抽屜 | 訊息中心 |
| 手指向**上**滑動 | 下方抽屜 | 控制中心 |

> 想像每個抽屜是貼在錶盤的某一邊,需要把它「拉進來」—— 抽屜在哪一邊,你的手指就要往相反方向滑。

從任一抽屜按下螢幕往**回到錶盤**的方向滑動,即可關閉抽屜回到錶盤。

## 第一次開機:互動引導

第一次開機(或在設定中重新觸發)時,Skaiwalk Watch 會在錶盤上層疊加一份互動引導:

### 階段 1:錶盤上的四方向提示

進入錶盤後,你會看到:

- **四條金色邊條** — 分別位於螢幕的上、下、左、右邊緣,以脈動透明度提示這四個方向各有抽屜可拉開。
- **中央 Release 提示** — 一段帶有滑動箭頭的動畫,示範「按下 → 滑動 → 放開」這個 Release 動作。

每當你成功進入一個抽屜後,該方向的邊條就會消失。例如向右滑動進入指令列表,左側那條邊條就會永久不再顯示。

### 階段 2:指令列表中的點擊提示

當你第一次進入指令列表時,引導會自動切換到第二階段:

- **中央 Tap 提示** — 一個脈動的圓圈,示範點擊動作。
- **文字提示** — 「點擊執行,或再次滑動進入 AI」,告訴你目前可以做兩件事:
  1. **Tap** 畫面中央被選中的功能 → 直接執行該功能(例如打開計時器)。
  2. **再次 Release**(同方向繼續滑動) → 進入更深層的 AI 頁面。

### 階段 3:結束

當你進入 AI 頁面後,引導完成,覆蓋層自動消失。後續每次開機都不會再顯示。

> **重新觸發**:如果想再看一次,在連接電腦的開發環境中,於 tshell(主控台)輸入
> `onboarding start`;一般使用者請至「設定 → 還原引導」(若你的版本提供此選項)。

## 主要頁面

### 錶盤(中央)

錶盤是手錶的首頁,顯示目前時間並提供下列資訊:

- **時間** — 大型時鐘,提供多款錶面樣式(數位、地球儀、Earth digital 等)
- **狀態列**(頂端) — 連線狀態、電量、配戴狀態、天氣圖示
- **小工具**(部分錶面) — 心率、媒體控制、計步等

#### 切換錶面

從錶盤往左/右**長距離拖曳**(不是 release),可以在多款錶面之間切換。
也可以從 [設定 → 錶盤](#設定-app) 進入完整選擇畫面。

> **狀態列特殊區**:在錶盤頂端中央輕輕點擊,可以快速進入「裝置變更橫條」(藍牙裝置切換、配對狀態)。

### 訊息中心(上方抽屜)

從錶盤往下滑動進入。功能:

- 列出所有未讀通知:訊息、來電紀錄、提醒、系統警告
- 每張卡片顯示:來源 App 圖示、發送者、時間、內容預覽
- **點擊卡片** → 開啟完整訊息(若應用支援)
- **左滑卡片** → 忽略
- **回覆**(若該訊息來源支援) → 進入語音轉文字介面回覆

### 控制中心(下方抽屜)

從錶盤往上滑動進入。提供常用快速設定:

| 控制項 | 說明 |
| --- | --- |
| 勿擾模式 | 關閉震動與通知聲音 |
| 顯示模式 | 切換 12 / 24 小時制 |
| 亮度滑桿 | 即時調整螢幕亮度 |
| 螢幕逾時 | 設定多久後自動關閉螢幕 |
| 尋找手機 | 觸發手機鈴聲(連線時) |

不需要進入「設定 App」就能調整。

### 指令列表(左側抽屜)

從錶盤往**右**滑動進入。這是手錶的主要 App 啟動器,以圓弧排列方式呈現:

- **預設項目**:計時器、手電筒、錄音機等(內建項目可在 [進階功能 → 自訂指令](#自訂指令-instruction) 中調整)
- **自訂指令**:從 Skaiwalk Phone App 推送的可執行指令,可設定觸發條件(間隔、一次性、特定時間)
- **AI 入口**:列表底部的 AI 圖示

操作方式:

- **手腕翻動 / 拖曳** → 在列表中捲動,中央那一項即為「被選中」
- **Tap 中央項目** → 執行被選中的功能
- **點擊底部 AI 圖示** 或 **再次 release** → 進入 AI 頁面
- **反方向滑回(向左)** → 回到錶盤

> 指令列表是 Skaiwalk Watch 與手機協同的核心:你在手機 App 寫的「打開家裡冷氣」這類指令,會以條目形式同步到這裡,在手錶上一鍵執行。

### AI 頁面(右側抽屜)

從錶盤往**左**滑動進入,或從指令列表底部點擊 AI 圖示。

- **大型麥克風按鈕** — Tap 開始語音輸入
- **對話歷史** — 上方顯示最近的問答對
- **打字模式**(部分版本) — 支援由手機端輸入文字傳送

進入時若沒有正在進行的對話,會自動開麥克風開始聆聽;說完話後手錶送往 Skaiwalk AI 後端(經由手機 App)取得回覆,文字 / 語音回應呈現在畫面上。

## App 一覽

下列 App 有些出現在 [指令列表](#指令列表左側抽屜),有些出現在 App 圓形網格(從指令列表繼續往下捲),
有些則需要被別的事件觸發(例如來電)。

### 時間相關

#### 時鐘 App

點擊錶盤即可進入,顯示放大版時間、農曆日期(若啟用)。提供多款錶面樣式切換。

#### 鬧鐘 App

iOS 風格卡片列表,每張卡片是一個鬧鐘:

- 顯示時間(例 07:30)、重複規則(週一/三/五)與啟用切換
- **Tap 卡片** → 編輯時間、星期、刪除
- 右下角 **+ 鈕** → 新增鬧鐘

鬧鐘響起時手錶會震動並顯示提示畫面;點一下可以延後,雙擊或長按可以解除。

> **同步**:手錶與手機間鬧鐘雙向同步,需要藍牙連線。

#### 計時器 App

倒數計時器。

- 用滑動 / 點擊設定分鐘 + 秒數
- **Start** → 開始倒數,大字顯示剩餘時間
- **Pause / Resume** / **Cancel** → 暫停 / 取消
- 倒數結束震動並播放鈴聲 → **Stop** 停止

完全離線運作。

### 健康與運動

#### 心率

手錶常駐量測心率(由 LCPU 處理)。錶面狀態列、控制中心、Exercise App 都能看到目前心率。長期紀錄會同步到 Skaiwalk Phone App。

#### 活動量

每天自動紀錄步數、活動時間、消耗熱量。資料儲存在手錶端,可在 Phone App 看詳細曲線。

#### Exercise(運動 App)

開始一場運動 session:

- 選擇活動類型(跑步、騎車、走路…)
- 即時顯示心率、距離、卡路里、時間
- **End** → 結束並儲存

部分運動類型會啟用更嚴格的姿態 / 步頻分析。

### 通訊

#### 訊息 App

集中管理所有來自手機 App 的通知。介面與 [訊息中心](#訊息中心上方抽屜) 抽屜一致,不過提供更完整的歷史紀錄與搜尋。

#### 來電(Incoming Call)

當配對的手機接到電話時,自動跳出此畫面。

- 顯示來電者名稱(或號碼)、來源 App 圖示
- **綠色 Accept** → 透過 BLE HFP 接聽
- **紅色 Hangup** → 拒接

通話結束或在手機端掛斷後自動關閉。

#### 語音轉文字(Speech)

點麥克風開始說話,語音傳到手機由雲端 STT 轉成文字後即時呈現,可以送出當作訊息或搜尋。

#### Skaiwalk AI

完整介紹見 [AI 頁面](#ai-頁面右側抽屜)。除了從右側抽屜進入,App 列表也可以直接開啟。

### 工具

#### 手電筒(Flashlight)

巨大的開 / 關按鈕,啟動後整個螢幕白光全亮。若你的版本啟用 RGB 控制面板,還可以選擇顏色。

#### QR Code

顯示手錶的 BLE MAC 編碼為 `https://skaiwalk.com/watch_id=...` 的 QR 碼。配對時用手機掃這個碼。

#### 計算機(Calculator)

四則運算,支援連續運算與清除。

#### 檔案瀏覽器(File Browser)

瀏覽手錶內部儲存。可以查看相片、錄音檔、AI 對話紀錄等檔案,選擇後可以送回手機備份。

#### 天氣(Weather)

顯示目前位置、氣溫、濕度、風速,以及 5 天預報。資料來自手機端,要保持藍牙連線。

#### 電量資訊(Battery)

完整版電量畫面:百分比、預估剩餘可用時間、目前是否充電中。

### 拍攝與媒體

#### 相機(Camera)— 手機相機遙控

不是手錶上的鏡頭,而是 **觸發手機相機快門**。透過 BLE HID 送 Volume-up 指令給手機,手機相機 App 會把它當作快門鍵。

需求:手機相機 App 支援音量鍵快門,且配對狀態下使用。

#### 錄音機(Recorder)

按下大型錄音按鈕開始錄;錄製中按鈕轉成方形停止指示。停止後檔案存在手錶內部,可以透過檔案瀏覽器送回手機。

#### 相片(Photo)

瀏覽手錶內部相片庫。網格縮圖 → Tap 看大圖 → 雙擊縮放 → 滑動切換。

#### 媒體控制(Media)

控制手機正在播放的音樂:播放/暫停、上一首、下一首、音量。卡片上會顯示目前曲名(若手機端有送)。

### 遠端控制

#### Mouse / Touchpad(手機滑鼠 / 觸控板)

把手錶當成手機的觸控板。手指在錶面上拖曳會移動手機螢幕上的游標,Tap = 左鍵,雙擊 = 雙擊,長按 = 右鍵,邊緣滑動 = 捲動 / 返回。需 BLE HID 連線。

### 娛樂

#### 恐龍跳跳(Game Dinosaur)

Chrome 風格的無限跑酷遊戲。Tap 螢幕 / 抬腕 → 跳;閃避仙人掌與飛行敵人,難度隨分數提高。完全離線。

### 系統

#### 設定 App

| 主分類 | 內容 |
| --- | --- |
| 勿擾模式 | 關閉震動 / 通知聲 |
| 亮度 | 滑桿調整螢幕亮度 |
| 螢幕逾時 | 設定螢幕自動關閉時間 |
| 顯示模式 | 12 / 24 小時制切換 |
| 手勢設定 | 調整手勢觸發靈敏度(release / tap)|
| 語言 | 介面語言切換 |
| 字級 | 小 / 中 / 大 |
| 系統資訊 | 裝置名稱、型號、韌體版本 |
| 還原裝置 | 恢復出廠設定(會清除所有資料)|
| 重新啟動 | 重開機 |

> 開發版韌體會多出一個「Developer」分類,內含工具與測試指令。Release 版本會自動隱藏。

#### 互動(Interact)

系統層級的對話畫面,用來處理:

- **配對 QR 碼顯示**(配對流程的一環)
- **尋找手錶** — 接到手機端「Find Watch」指令時自動進入,震動並亮燈
- **電量過低警告** — 電量低於門檻(通常 15%)自動跳出
- **裝置配對狀態** — 顯示連線狀態、配對結果

通常由系統事件自動觸發,使用者不需要手動進入。

## 進階功能

### 自訂錶盤

從 [設定 → 錶盤](#設定-app) 進入錶盤選擇畫面。內建錶盤包含:

- 數位錶面
- 地球儀(Earth digital)
- 多款 Lottie 動畫(快樂、登山、指紋、材質載入器…)

進階使用者可以從 Skaiwalk Phone App 下載額外錶盤;支援基於 JSON 描述的動態錶面引擎。

### 自訂指令(Instruction)

[指令列表](#指令列表左側抽屜) 中除了內建項目以外,所有條目都來自手機端的「Skaiwalk 指令」。

在 Skaiwalk Phone App 中:

1. 新增指令 → 選擇觸發類型(Interval / Once / 特定時段)
2. 寫下指令內容(自然語言或結構化動作)
3. 推送到手錶 → 立即出現在指令列表

每個指令在手錶端都可以單獨開關(切換鈕),不需要每次回手機操作。

### 手勢校準

「設定 → 手勢設定」可以調整 release / tap 的觸發門檻,適合手腕較細或皮膚較乾的使用者。校準時手錶會請你做幾次標準動作,自動記錄你的力道與時間範圍。

### 韌體更新(DFU)

新版韌體推送時,Skaiwalk Phone App 會通知你。流程:

1. 手機端開始 DFU 推送
2. 手錶進入更新模式,畫面顯示進度條(請保持手錶於充電底座或電量充足)
3. 完成後自動重啟

> **更新中請勿關閉手機 App 或斷開藍牙**,否則需要重新進入 DFU 模式。

### 互動引導重新觸發(進階)

## 連線與資料同步

### 完全離線可用的 App

時鐘、鬧鐘、計時器、計算機、手電筒、QR Code、檔案瀏覽器、相片、恐龍跳跳、電量、心率(本地讀取)、活動量(本地紀錄)。

### 需要藍牙連線的 App

訊息、來電、天氣、媒體控制、相機遙控、Mouse / Touchpad、語音轉文字、AI、互動配對、Exercise(部分詳細統計)。

### 同步原則

- 健康 / 活動資料 → 由手錶持續紀錄,連線時批次上傳手機
- 訊息 / 通知 → 即時推送
- 韌體 / 錶盤 → 由手機推送

## 故障排除

### 手錶無法開機

1. 確認電量是否充足(放上充電底座 30 分鐘以上)
2. 長按側邊按鈕 10 秒強制重啟
3. 仍無法開機 → 聯繫客服

### 手機 App 找不到手錶

1. 確認手錶 BLE 為開啟(設定 → 系統資訊查看)
2. 重新進入手錶端的 [QR Code App](#qr-code) 顯示新 QR 碼
3. 在手機端「忘記裝置」後重新配對

### 通知沒有同步

1. 手機端授權 Skaiwalk App 通知存取權
2. 檢查手錶端 [勿擾模式](#控制中心下方抽屜) 是否啟用
3. 重新啟動手錶與手機 App

### AI / 語音不回應

1. 確認手機端網路通暢
2. 確認手機 App 為前景或背景常駐
3. 在 [設定](#設定-app) 確認 AI 服務啟用中

### 手勢不靈敏

至 [手勢校準](#手勢校準) 重新訓練;若問題持續,檢查螢幕是否有水珠 / 油漬。
