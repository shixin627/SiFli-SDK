# 恐龍跑酷遊戲 (Dinosaur Runner Game)

## 遊戲概述

這是一款基於手勢控制的跑酷遊戲，玩家控制一隻恐龍在奔跑過程中躲避障礙物並攻擊敵人。遊戲採用暗色主題設計，提供流暢的遊戲體驗和豐富的互動機制。

## 遊戲特色

### 1. 雙重跳躍系統
- **一段跳**：在地面時使用 Tap 手勢進行第一次跳躍
- **二段跳**：在空中時可以再次使用 Tap 手勢進行第二次跳躍
- 二段跳時會有視覺回饋效果（恐龍會短暫放大）

### 2. 投射攻擊系統
- 使用 Release 手勢（握拳後快速張開）發射紅色彈珠
- 彈珠可以擊毀飛行敵人，獲得額外分數
- 最多同時存在 5 個彈珠

### 3. 雙重障礙系統
#### 地面障礙物
- 灰色矩形方塊
- 隨機高度 (40-60 像素)
- 無法被攻擊摧毀，只能跳躍躲避
- 出現機率：60%

#### 飛行敵人
- 使用 `img_enemy` 圖片顯示
- 隨機高度飛行 (Y: 150-280)
- 可以被彈珠擊毀
- 擊毀後獲得 5 分額外獎勵
- 出現機率：40%

## 操作方式

### 手勢控制
| 手勢 | 功能 | 說明 |
|------|------|------|
| Tap（輕點） | 跳躍 | 地面：一段跳<br>空中：二段跳 |
| Release（張開手掌） | 發射彈珠 | 攻擊飛行敵人 |
| 點擊屏幕 | 開始/重啟 | 遊戲準備或結束時 |

### 遊戲狀態
- **READY**：遊戲準備，點擊屏幕開始
- **RUNNING**：遊戲進行中
- **OVER**：遊戲結束，顯示 "GAME OVER" 和 "Tap to restart"

## 計分系統

- **基礎分數**：每個障礙物或敵人通過後 +1 分
- **擊殺獎勵**：成功擊毀飛行敵人 +5 分
- **擊殺統計**：單獨顯示擊毀敵人的數量

## 遊戲參數

### 視窗設定
- 螢幕尺寸：466 x 466 像素
- 地面位置：Y = 350

### 恐龍設定

- 位置：X = 80
- 使用圖片：`img_dinosaur`

- 遊戲刷新率：30ms/幀（約 33 FPS）

- 障礙物寬度：25 像素
- 障礙物速度：6 像素/幀

- 最大同時存在數量：3 個

### 敵人設定
- 敵人尺寸：40 x 40 像素
- 飛行範圍：Y 150-280
- 使用圖片：`img_enemy`

### 彈珠設定
- 彈珠尺寸：16 x 16 像素
- 彈珠速度：12 像素/幀
- 彈珠顏色：#FF5555（紅色）
- 形狀：圓形

## UI 元素

### 顯示資訊（右上角）
1. **分數顯示**：白色文字顯示當前總分
2. **擊殺數統計**：紅色文字顯示擊毀敵人數量
3. **手勢信心度**：灰色文字顯示 Release 手勢的識別信心度

### 遊戲元素
- **地面線**：灰色線條標示地面位置
- **恐龍**：使用 `img_dinosaur` 圖片
- **障礙物**：灰色矩形方塊（圓角 3px）
- **敵人**：使用 `img_enemy` 圖片
- **彈珠**：紅色圓形

### 按鈕
- **Exit 按鈕**：位於底部中央，點擊退出遊戲

## 碰撞檢測

遊戲使用 **AABB（軸對齊邊界框）碰撞檢測**：
- 恐龍與地面障礙物碰撞 → 遊戲結束
- 恐龍與飛行敵人碰撞 → 遊戲結束
- 彈珠與飛行敵人碰撞 → 敵人消失，獲得獎勵分數

## 遊戲技巧

1. **合理使用二段跳**
   - 一段跳通常足以跳過地面障礙
   - 二段跳用於應對連續障礙或躲避空中敵人

2. **優先攻擊飛行敵人**
   - 擊毀敵人可獲得 5 倍獎勵分數
   - 提前發射彈珠，確保命中

3. **觀察手勢信心度**
   - 信心度顯示在右上角
   - 確保手勢動作標準以獲得更好的識別率

4. **節奏掌控**
   - 障礙物以固定速度移動
   - 熟悉節奏後可以預判跳躍時機
